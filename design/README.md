# Design

Design system, prototypes, branding, and assets.

## What belongs here

- `figma/` — Figma file links, component library, screen designs
- `design-system/` — Tokens (colors, spacing, typography, shadows, radius), components (Button, Card, Input, Avatar, Badge, Sheet, Toast), platform adaptations (iOS/Android)
- `prototypes/` — Interactive flows: onboarding, discover, chat, meetup, safety
- `branding/` — Logo (mark + wordmark), color palette, typography, icon style, illustration style
- `assets/` — Exported PNG/SVG/WebP for mobile (1x, 2x, 3x), Lottie animations
- `handoff/` — Specs for developers: screen specs, interaction notes, accessibility requirements

## Key Screens

1. Welcome / "What are you looking for"
2. Auth (email/phone OTP)
3. Profile creation (required → optional)
4. Home / Feed (college/country/all tabs)
5. Discover / Search (filters, results, profile)
6. Profile view (actions: message, coffee, follow, report)
7. Chat list + conversation
8. Meetup invite flow (propose → safety → confirm)
9. Communities list + group chat + events
10. Notifications center
11. Settings (privacy, notifications, blocked users)
12. Safety guidance (meetup, reporting)
